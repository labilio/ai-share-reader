# Grok share example

## Input

```
https://grok.com/share/{share_id}
```

## Output

```
# 最强AI排名平台与评估

**User:** 目前最强AI排名的平台有哪些？

**Assistant:** 是的，有几个权威平台可以帮助你了解"最强AI"的排名。这些平台通过基准测试、大众投票或性能竞赛来评估模型：

**大众投票平台**

- **LMArena (前LMSYS Chatbot Arena)**: 众包平台，用户通过匿名侧边比较两个模型的响应并投票。基于Elo评分系统，收集数百万用户投票。目前顶级模型：Gemini 3 Pro (Elo 1490)、Gemini 3 Flash (Elo 1480)、Grok 4.1 Thinking (Elo 1477)

**专家/基准测试平台**

- **SEAL Leaderboards (Scale AI)**: 专家设计评估，焦点在编码、推理、安全等特定任务。顶级模型：Claude Opus 4.5（软件工程领先）、GPT-5.2（金融法律推理强）、Gemini 3 Pro（知识前沿和视觉任务顶尖）
- **llm-stats.com AI Leaderboards**: 综合比较平台，覆盖LLM、图像生成、视频等多领域。顶级：Gemini 3 Pro、Claude Opus 4.5、GPT-5.2
- **Hugging Face Open LLM Leaderboard**: 专注开源模型，基于MMLU、HellaSwag等标准化基准

**算力/性能竞赛平台**

- **MLPerf (MLCommons)**: 行业标准竞赛，测量AI系统训练和推理的速度和效率，更评估系统整体而非单个模型

这些平台不是单一"权威机构"，因为AI评估主观且多维（如Gemini视觉强，Claude编码强），建议结合多个来源避免偏见。
```
